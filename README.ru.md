> Учебный проект 2024 года: быстро вернуться в форму. Оставляем как есть.

**Змейка** — небольшая классическая аркада на Python и Pygame. В 2024 году это была короткая попытка снова собрать цельную программу своими руками.

По работе код писался всегда, но чаще это были интеграции и скрипты: bash, bat/cmd, PowerShell, Python, Lua (в том числе интеграционные профили Modbus) и встроенные скриптовые языки в средах систем безопасности. «Змейка» стоит рядом с этой практикой как учебный снимок, а не как смена ремесла.

В игре:

- управление стрелками
- яблоки и препятствия
- нужно не врезаться в себя

```text
python -m pip install -r requirements.txt
python the_snake.py
```
