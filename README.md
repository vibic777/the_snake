# the_snake

[Русский](README.ru.md) · **English**

> A 2024 exercise: get back into practice quickly. Kept as it is.

**the_snake** is a small classic Snake game in Python and Pygame. It was a short way back to writing a whole program, not a change of craft.

Day-to-day work had always been code, mostly integrations and scripts: bash, Windows `bat`/`cmd`, PowerShell, Python, Lua (including Modbus integration profiles), and the built-in scripting languages of security and integration systems. Snake sits beside that practice as a learning snapshot from 2024.

In the game you steer with the arrow keys, collect apples, and avoid the hazards and your own tail.

```text
python -m pip install -r requirements.txt
python the_snake.py
```

**GitHub About:** A 2024 learning project: classic Snake in Python and Pygame, kept as a quick return to practice.
